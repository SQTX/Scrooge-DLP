Install a new agent

Aktualnie: nie ma jeszcze pre-built binarki w GitHub Releases ani install scriptu — to milestone „Wazuh-flow". Tymczasem instalacja jest manualna:

  1. Sklonuj repo: git clone https://github.com/SQTX/Scrooge-DLP
  2. Wygeneruj token na managerze: make dev-bootstrap
  3. Skopiuj dev-certs/ca.pem na maszynę agenta
  4. Konfig /etc/scrooge/agent.yaml
  5. Build i start: ./deploy/dev/rebuild-and-restart-agent.sh
