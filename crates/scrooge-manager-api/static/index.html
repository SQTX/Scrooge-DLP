Install a new agent

Aktualnie: nie ma jeszcze pre-built binarki w GitHub Releases ani install scriptu — to milestone „Wazuh-flow" (poza zakresem Milestone 1). Tymczasem instalacja jest manualna:

  1. Sklonuj repo na docelową maszynę: git clone https://github.com/SQTX/Scrooge-DLP
  2. Wygeneruj token: make dev-bootstrap (na managerze)
  3. Skopiuj dev-certs/ca.pem na maszynę agenta
  4. Konfig /etc/scrooge/agent.yaml (endpoint + token + ca path)
  5. Build i start: ./deploy/dev/rebuild-and-restart-agent.sh

Pełen guide: deploy/dev/README.md
